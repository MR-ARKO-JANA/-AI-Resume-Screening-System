Getting Started

1

Upload Resume

Drag & drop or browse to upload candidate resumes in PDF, DOC, or DOCX format.

2

Add Job Description

Paste the job description or select from saved templates. The AI uses this to match skills.

3

AI Screening

Click "Start AI Screening" and our AI will analyze the resume and generate a match score.

Features Guide

AI-Powered Screening

Core

Our AI engine analyzes resumes against job descriptions using three key metrics:

  • Skill Match (60%)
    Technical and soft skills comparison
  • Keyword Match (30%)
    JD keyword relevance scoring
  • Experience (10%)
    Years and level assessment

Candidate Management

Manage all your candidates in one place with powerful tools:

  • Filter by status: Shortlisted, Pending, Rejected
  • Bulk actions: Select multiple and shortlist/reject
  • Export candidate data as CSV
  • Detailed profile view with GitHub & LinkedIn analysis

Profile Lookup

New

Deep-dive into candidates' online profiles:

  • GitHub analysis: repos, stars, languages, commit activity
  • LinkedIn insights: experience, certifications, skills
  • AI Summary: AI-generated professional summary

Customizable Scoring

Fine-tune AI scoring to your needs:

  • Adjust skill, keyword, and experience weights
  • Visual scoring chart preview
  • Total must equal 100% (validated)

AI Recruiter supports PDF, DOC, and DOCX file formats. The maximum file size is 5MB per resume. For best results, we recommend uploading PDF files as they preserve formatting consistently.

The AI scoring system uses three weighted components:

  • Skills Match (60%) — Compares the candidate's technical and soft skills against job requirements
  • Keyword Match (30%) — Analyzes keyword density and relevance from the job description
  • Experience (10%) — Evaluates years of experience and career level

You can customize these weights in Settings → AI Scoring.
